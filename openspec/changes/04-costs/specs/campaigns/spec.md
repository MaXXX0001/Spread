# Spec Delta

## ADDED Requirements

### Requirement: Кампанія з витратами не видаляється
Система MUST NOT видаляти кампанію, для якої є хоча б одна витрата: витрати потрібні для звітів. Адмін бачить повідомлення про причину і пораду вимкнути кампанію.

#### Scenario: Видалення кампанії з витратою на її сторінці
- **WHEN** адмін видаляє зі сторінки редагування кампанію без кліків, але з витратою
- **THEN** кампанію не видалено, адмін бачить повідомлення про причину

#### Scenario: Масове видалення
- **WHEN** адмін масово видаляє дві кампанії без кліків, з яких лише одна має витрати
- **THEN** видалено лише кампанію без витрат, адмін бачить повідомлення, скільки кампаній не видалено і чому
