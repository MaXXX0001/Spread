# Spec Delta

## ADDED Requirements

### Requirement: Обмеження частоти постбеків
Вебсервер перед ендпоінтом `/p/{key}` SHALL обмежувати частоту запитів з однієї IP-адреси: 20 запитів за секунду зі сплеском до 100. Запити понад ліміт SHALL отримувати `429` і MUST NOT потрапляти в буфер постбеків. Ліміт задається конфігурацією nginx (`deploy/`), а не кодом застосунку, тож однаково діє для Laravel- і Go-версії гарячого шляху. Редірект `/c/{alias}` цим лімітом MUST NOT обмежуватися.

#### Scenario: Флуд з однієї адреси
- **WHEN** з однієї IP за секунду приходить 300 запитів на `/p/{key}`
- **THEN** частина з них отримала `429`, а в буфер потрапили лише прийняті

#### Scenario: Звичайна мережа
- **WHEN** CPA-мережа шле 5 постбеків за секунду
- **THEN** усі отримали `200`

#### Scenario: Редірект без ліміту
- **WHEN** з однієї IP за секунду приходить 300 запитів на `/c/{alias}`
- **THEN** жоден не отримав `429`
